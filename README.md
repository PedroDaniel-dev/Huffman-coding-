# Huffman Coding

Java implementation of the Huffman Coding algorithm for the Data Structures course at UNIRIO (Federal University of the State of Rio de Janeiro).

## Overview
This project implements the Huffman Coding algorithm, a lossless data compression technique based on character frequency analysis.

This project builds a Huffman Tree from a input string and generates the corresponding binary representation based on character frequencies.

## Features
*   Character frequency analysis
*   Huffman Tree construction
*   Binary code generation for each character
*   String encoding using Huffman Coding
*   Retrieval of the encoded binary sequence
*   Custom Doubly Linked List (`LDE`) implementation

## How the Algorithm Works
The Huffman Tree is built using the following process:

1.  Count the frequency of each character in the input string.
2.  Create a node for each unique character.
3.  Sort the nodes by frequency.
4.  Remove the two nodes with the lowest frequencies.
5.  Create a new parent node whose frequency is the sum of the removed nodes.
6.  Insert the new node back into the ordered structure.
7.  Repeat the process until only one node remains.
8.  The remaining node becomes the root of the Huffman Tree.

Binary codes are generated by traversing the tree:
*   Left child = 0
*   Right child = 1

The code assigned to a character corresponds to the sequence of bits encountered from the root to its leaf node.

## Example

**Input:**
`DAFDBDCADACBEDDECACDDABDABDBDD`

**Encoded output:**
`011110000110010111101111011101001001001101111101001111100111110011000`

## Design Constraints
This project was developed according to the constraints defined for the assignment:

*   No built-in Java data structures were used for the Huffman implementation.
*   The Huffman Tree was built using custom nodes and supporting data structures (`ILista`, `LDE`, `Item`).
*   A custom sorting method was implemented to support the tree construction process.
*   The project is designed to be built using Gradle.
